Reveal-on-scroll once. Stagger max 8 items. Respect prefers-reduced-motion. Hover effects only under (hover:hover) and (pointer:fine); touch gets a .98 press scale. No scroll hijacking. 7. ANTI-GARBAGE RULES (learned from a failed build)
(a) No unlabeled icon-only mystery buttons; no unicode glyph icons.
(b) No paragraphs in monospace; no body text lighter than --ink-2 on white.
(c) No meaningless abstract blobs as product art; no half-empty tiles; every tile has a defined composition, content and padding.
(d) No empty-catalogue state while data exists. If Supabase fails or is empty: when flags.allowSeedFallback show seed products labelled "Preview data" and disable purchase; otherwise show a designed "Catalogue opening soon" state with an email capture.
(e) Header must always include the wordmark, labelled navigation (desktop), a real search field or search button, saved, cart with count and account.
(f) Everything visible must work: no href="#", no dead buttons, no placeholder routes. Do not render controls for features not built yet.
(g) Responsive means designed per breakpoint (320, 360, 390, 430, 768, 1024, 1280, 1440, 1920), with no horizontal scroll, no clipped text, no stretched images, 44px minimum touch targets, safe-area padding.
(h) No lorem ipsum, no placeholder names.
